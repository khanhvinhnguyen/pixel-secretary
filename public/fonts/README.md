# Font KVN-97Bold

Đặt file font Việt hoá vào thư mục này (một trong các tên sau):

- `KVN-97Bold.woff2` (khuyến nghị)
- `KVN-97Bold.woff`
- `KVN-97Bold.ttf`

Nguồn: bản font game KVN-97 Bold bạn đã có bản quyền sử dụng. App sẽ tự `@font-face` từ `/fonts/`.

Nếu chưa có file, UI dùng fallback monospace pixel tạm thời.
