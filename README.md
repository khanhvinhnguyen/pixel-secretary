# Pixel Secretary

Pixel Secretary is a local-first desktop todo and reminder app planned as a lightweight Tauri application.

## Development

Install dependencies:

```sh
npm install
```

Run the web development server:

```sh
npm run dev
```

Run the desktop app:

```sh
npm run desktop:dev
```

Build the frontend:

```sh
npm run build
```

Build the desktop app:

```sh
npm run desktop:build
```

Task management, reminders, local storage, and pixel assistant UI are planned for later implementation steps.
